Use Case : Stroke Prediction
Objective / Problem Statement
Untuk memprediksi risiko stroke pada pasien berdasarkan data demografis dan kondisi kesehatan, guna mendukung deteksi dini dan tindakan pencegahan yang lebih efektif.
Untuk mengidentifikasi faktor-faktor risiko utama yang paling berpengaruh terhadap kejadian stroke sehingga dapat menjadi dasar rekomendasi medis berbasis data.
Business Benefit
Membantu tenaga medis dan institusi kesehatan dalam mengidentifikasi pasien berisiko tinggi stroke secara lebih cepat dan akurat.
Meningkatkan efisiensi alokasi sumber daya medis dengan memprioritaskan penanganan pada pasien berisiko tinggi.
Mendukung program pencegahan stroke berbasis data untuk mengurangi angka kejadian dan biaya penanganan stroke.
Expected Outcome
Model klasifikasi machine learning yang mampu memprediksi risiko stroke dengan AUC-ROC minimal 0.80.
Visualisasi distribusi faktor risiko stroke pada populasi dataset (usia, kadar glukosa, BMI, hipertensi, dll.).
Laporan analisis lengkap yang dapat digunakan sebagai dasar rekomendasi pencegahan stroke.
Methodology / Analytic Technique
Descriptive Analysis: eksplorasi statistik untuk memahami distribusi dan karakteristik data.
Predictive Analysis (Supervised Learning - Classification): membangun model prediksi stroke menggunakan algoritma seperti Logistic Regression, Decision Tree, Random Forest, dan XGBoost.
Feature Importance Analysis: mengidentifikasi variabel paling berpengaruh terhadap risiko stroke.
Success Criteria
AUC-ROC &gt;= 0.80 pada data uji.
Recall (sensitivitas) &gt;= 0.75 untuk kelas stroke positif agar kasus stroke tidak terlewat.
F1-Score &gt;= 0.65 sebagai keseimbangan precision dan recall.

Use Case : Stroke Prediction
Data Cleaning
Imputasi Missing Values BMI: 201 nilai N/A pada kolom 'bmi' diisi menggunakan median BMI berdasarkan kelompok usia dan jenis kelamin.
Penghapusan Duplikat: memeriksa dan menghapus data duplikat untuk menjaga integritas dataset.
Penanganan kategori langka: 1 baris gender 'Other' dipertimbangkan untuk dihapus karena tidak representatif.
Transformasi &amp; Encoding
Label Encoding: variabel biner 'ever_married' (Yes/No → 1/0) dan 'Residence_type' (Urban/Rural → 1/0).
One-Hot Encoding: variabel multi-kategori 'gender', 'work_type', 'smoking_status' untuk menghindari ordinal bias.
Normalisasi: Min-Max Scaling pada variabel numerik (age, avg_glucose_level, bmi) agar model tidak bias terhadap skala besar.
Penanganan Class Imbalance
SMOTE (Synthetic Minority Over-sampling Technique): membuat sampel sintetis kelas minoritas (stroke=1) untuk menyeimbangkan proporsi kelas.
Evaluasi menggunakan F1-Score, AUC-ROC, dan Recall — bukan hanya Accuracy, karena data tidak seimbang.
Pembagian Dataset
Split 80% data latih (training set) dan 20% data uji (testing set).
Stratified split: memastikan proporsi kelas stroke terjaga di kedua subset.

Rencana Deployment
Model terbaik disimpan menggunakan library joblib atau pickle untuk digunakan kembali tanpa melatih ulang.
Membangun antarmuka web berbasis Streamlit atau Flask: tenaga medis memasukkan data pasien dan mendapatkan prediksi risiko stroke secara real-time.
Dashboard visualisasi menampilkan distribusi faktor risiko dan tingkat kepercayaan prediksi.

Monitoring Pasca Deployment
Pemantauan distribusi data input secara berkala untuk mendeteksi data drift.
Evaluasi ulang performa model minimal setiap 6 bulan atau jika ditemukan penurunan performa signifikan.
Pembaruan model dilakukan jika akurasi turun di bawah threshold yang ditetapkan.
Feedback
Pengumpulan feedback dari tenaga medis terkait relevansi dan kegunaan prediksi model.
Analisis misclassification untuk memahami pola kesalahan model dan dijadikan dasar perbaikan.
